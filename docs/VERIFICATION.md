## Исправления, найденные при проверке

- Middleware сессии Backpack заменён стандартным middleware Laravel: поддерживается текущий формат HMAC хеша сессии. Добавлен регрессионный тест с настоящим входом по паролю.
- Для связей автора и категории использован стандартный бесплатный столбец Backpack `select`; вместо JSON отображаются email и название.
- Удалена зависимость аватаров от Gravatar: используется загруженный файл или локальная заглушка.
- Тест создания заявки использует фактически присвоенный ID: MySQL не обязан сбрасывать AUTO_INCREMENT при откате транзакции.
